# mstudio 视觉规范

2026-10-15：用户确认以当前工作区样式为准。本文件为现行视觉规范，统一应用的纸面、石墨文字和朱红强调色；早期概念与历史修订中的冲突视觉规则由本文件取代。范围为视觉呈现，不增加功能或改变生成、编辑、保存等业务行为。

[独立 HTML 检查页](../previews/design-spec.html) 展示配色、字级、几何与交互状态；它是样式快照，修改规范时需同步维护。

## 层级

- 工作台使用 `--desk-bg`；侧栏使用 `--desk-sidebar`；内容卡片与浮层使用 `--desk-surface`。
- 保留暖纸色、中性浅色、冷灰色三套已有外观。共用样式通过现有颜色变量派生，避免固定色值覆盖用户选择。
- 朱红用于当前工作区标记、选中图标、段落编号及既有状态；普通标题和工具文字保持石墨色。
- 高对比度外观沿用原有较强边界色。

## 字体

| 用途 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 页面主标题 | 26px | 600 | 36px |
| 配置页标题 | 22px | 600 | 30px |
| 面板标题 | 17px | 600 | 24px |
| 分组标题 | 13–15px | 600 | 20–22px |
| 内容正文 | 14px | 400 | 24px |
| 控件标签 | 13px | 400–500 | 20px |
| 辅助说明 | 12px | 400 | 18–20px |

系统字体优先；编号、时长、时间码使用 `--ui-mono` 与等宽数字。脚本正文保留 15px / 26px 的阅读规格。

## 尺寸与间距

- 间距基础序列为 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40px。
- 普通按钮、输入和选择框高 32–34px；面板中的紧凑操作高 28px。
- 普通图标为 17–18px，面板标题图标为 20px；辅助操作图标为 16px。
- 行内操作使用 `ui/ActionButton`：17px 图标、13px 文字、400 字重、17px 行高、6px 图文间距、32px 最小高度、5px 8px 内边距。默认透明底、无边框、6px 圆角；等待中的文案预留宽度，避免相邻操作位移。
- 控件圆角 6px，卡片圆角 8px，弹窗圆角 12px；脚本文档与手册纸面使用 3px。
- 配置页标题、列表和操作区共用最大 1160px 的内容网格；通用设置保留 760px 的阅读宽度。
- 时间线片段尺寸与轨道几何、画布坐标、媒体宽高比由原有组件负责，不由视觉规范更改。

## 状态

- 默认：普通行内操作与图标操作使用透明背景、石墨文字；输入框保留柔和边界。主操作使用墨色实底和浅色文字。
- 悬停：共享操作控件使用 `--ui-hover`，由侧栏色以 55% 混合透明色得到；不是强制所有控件变红。
- 选中：行内操作、图标操作的 `aria-pressed="true"`，以及菜单触发器的展开状态，使用 `--ui-selected`（6% 朱红与表面色混合）、朱红文字和 1px 内边界。导航、媒体、画布与时间线保留各自的语义标记，不全局套用按钮底色。
- 按下：共享操作控件使用 `--ui-pressed`（12% 石墨色与表面色混合）及轻微内阴影，即时响应，不播放过渡；持续选中与鼠标按下是不同状态。
- 键盘焦点：按钮、链接、页签等使用 2px 的 `--ui-focus-ring` 外轮廓、2px 偏移；该变量引用 `--desk-control-strong`，随主题使用强对比中性色。复选框、单选框与滑块的轮廓偏移为 3px。
- 输入焦点：设置与弹窗中的输入使用 `--desk-control-strong` 边框及 2px 的 `--ui-focus` 淡色圈，不改变元素几何。
- 禁用：共享控件透明度为 0.4，使用不可用光标，保留真实禁用逻辑；忙碌按钮透明度为 0.8，使用等待光标。
- 错误：使用 `--ui-danger`（`#B4372B`）边框与可读错误文字；错误输入聚焦时保留错误边框及淡红焦点圈，不仅依靠颜色表达。
- 只读：文本输入使用侧栏底色；复选框、单选框与滑块使用朱红强调色。
- 菜单：容器内边距 4px、圆角 8px、细边界与浮层阴影；菜单项最小高度 32px、上下内边距 6px、13px 字号、20px 行高、4px 圆角。选中、悬停、禁用反馈由共享状态样式负责。

## 实现入口

`frontend/src/styles/visual-system.css` 在应用基础样式之后加载，定义共用变量并按职责导入：

- `visual-controls.css`：基础控件、选择框与滚动条。
- `visual-library.css`：导航、项目库、公共素材与手册。
- `visual-settings.css`：模型、Agents、Skills、工具、通用设置。
- `visual-workspace.css`：工作栏、素材栏及字幕／配音面板。
- `visual-canvas.css`：制作画布、镜头说明及浮动工具。
- `visual-timeline.css`：时间线与预览控制。
- `visual-conversation.css`：对话、任务日志、输入区及引用选择器。
- `visual-dialogs.css`：弹窗、生成任务、菜单与模型表单。
- `control-states.css`：共享悬停、按下、选中、焦点、禁用与菜单状态。
- `interaction-feedback.css`：复合状态、菜单方向与进出节奏、危险操作分隔及长菜单滚动边界。

`color-tokens.css` 维护三套外观及高对比度颜色；`action-button.css` 维护行内操作几何；`motion.css` 维护共享动效。

已确认的 `clip-inspector.css`、`script-editorial.css` 保留其局部规格。后续组件优先引用共用变量；组件自身几何与媒体显示样式保持局部管理。

## 动效

- `motion.css` 统一维护缓动与时长：控件 120ms、页面 160ms、对话框进入 180ms、退出 120ms。高频菜单单独使用进入 120ms、退出 80ms。
- 配置页与工作区仅在导航切换时淡入；编辑、自动保存和对话更新不会重播。快速切换会取消上一段动画。
- 页面过渡只改变透明度，不动画化布局尺寸；拖动、缩放和时间线定位保持直接响应。
- 弹层避免缩放文字；有关闭状态的 Radix 弹层分别应用进入与退出规则。
- 动画结束不保留 transform；系统启用减少动态效果时关闭装饰性过渡。
- 清理样式时优先删除确定被覆盖的同选择器声明，以及源代码中已无使用者的旧选择器，保留局部几何规则。

## 连续操作反馈（2026-10-15）

- 状态按组合验收：选中后悬停保留朱红语义，底色由 6% 增至 10%；按下即时使用按压底色，松开恢复悬停或选中。不要用放大缩小按钮制造反馈。
- 菜单按实际避让后的 `data-side` 从触发器方向移动 3px 并淡入，120ms 结束；退出仅淡出 80ms，退出期间不接收点击。菜单文字不缩放，菜单项高亮直接跟随指针与键盘，不累积延迟过渡。
- 菜单中普通操作与危险操作交界使用细分隔线，保持原有顺序与可访问名称，不添加解释小字。
- 长菜单限制在可用窗口高度，内部滚动不传递给底层页面；鼠标与键盘都不能触发禁用项。
- 菜单、选择器必须能在原生 `dialog` 顶层内使用，浮层挂载到当前弹窗内。Esc 先关闭最内层菜单，选择结束后恢复触发器焦点；不因提高 z-index 破坏焦点隔离。
- 忙碌操作继续阻止重复提交，但保留 0.8 透明度与等待光标；不可用状态为 0.4。不能把“正在执行”表现成“无法操作”。
- 验收使用实际共享组件页面 `frontend/tests/control-states.html`，覆盖打开、选择、Esc、禁用跳过、原生弹窗嵌套、快速连续操作和减少动态效果；独立 HTML 仅用于静态规范查看，不代替这些交互检查。

## 验证

构建、既有前端测试及格式检查；在桌面应用中逐页检查实际数据、滚动、编辑焦点、长标题、选中和弹窗。视觉验证不等同于重新验证模型生成或媒体导出结果。
