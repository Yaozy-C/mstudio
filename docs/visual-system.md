# mstudio 视觉规范

本轮以已确认的片段属性与脚本页为样板，统一应用的纸面、石墨文字和朱红强调色。范围为视觉呈现，不增加功能或改变生成、编辑、保存等业务行为。

## 层级

- 工作台使用 `--desk-bg`；侧栏使用 `--desk-sidebar`；内容卡片与浮层使用 `--desk-surface`。
- 保留暖纸色、中性浅色、冷灰色三套已有外观。共用样式通过现有颜色变量派生，避免固定色值覆盖用户选择。
- 朱红用于当前工作区标记、选中图标、段落编号、编辑焦点及既有状态；普通标题和工具文字保持石墨色。
- 高对比度外观沿用原有较强边界色。

## 字体

| 用途 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 页面主标题 | 26px | 600 | 36px |
| 配置页标题 | 22px | 600 | 30px |
| 面板标题 | 17px | 600 | 24px |
| 分组标题 | 13–15px | 600 | 20–22px |
| 内容正文 | 14px | 400 | 24px |
| 控件标签 | 13px | 400–500 | 20px |
| 辅助说明 | 12px | 400 | 18–20px |

系统字体优先；编号、时长、时间码使用 `--ui-mono` 与等宽数字。脚本正文保留 15px / 26px 的阅读规格。

## 尺寸与间距

- 间距基础序列为 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40px。
- 普通按钮、输入和选择框高 32–34px；面板中的紧凑操作高 28px。
- 普通图标为 17–18px，面板标题图标为 20px；辅助操作图标为 16px。
- 控件圆角 6px，卡片圆角 8px，弹窗圆角 12px；脚本文档与手册纸面使用 3px。
- 配置页标题、列表和操作区共用最大 1160px 的内容网格；通用设置保留 760px 的阅读宽度。
- 时间线片段尺寸与轨道几何、画布坐标、媒体宽高比由原有组件负责，不由视觉规范更改。

## 状态

- 默认：柔和边框与稳定的文字对比度。
- 悬停：轻微表面明度变化或边框加深。
- 选中：纸面底色、清晰边界及少量朱红标记；避免整片红色文字。
- 聚焦：朱红边框或既有键盘焦点圈；聚焦不改变元素几何。
- 禁用：保留既有禁用逻辑与反馈，不用样式伪造可用状态。
- 错误：保留既有文字、语义和朱红提示，不仅依靠颜色表达。

## 实现入口

`frontend/src/styles/visual-system.css` 在应用基础样式之后加载，定义共用变量并按职责导入：

- `visual-controls.css`：基础控件、选择框与滚动条。
- `visual-library.css`：导航、项目库、公共素材与手册。
- `visual-settings.css`：模型、Agents、Skills、工具、通用设置。
- `visual-workspace.css`：工作栏、素材栏及字幕／配音面板。
- `visual-canvas.css`：制作画布、镜头说明及浮动工具。
- `visual-timeline.css`：时间线与预览控制。
- `visual-conversation.css`：对话、任务日志、输入区及引用选择器。
- `visual-dialogs.css`：弹窗、生成任务、菜单与模型表单。

已确认的 `clip-inspector.css`、`script-editorial.css` 保留其局部规格。后续组件优先引用共用变量；组件自身几何与媒体显示样式保持局部管理。

## 动效

- `motion.css` 统一维护缓动与时长：控件 120ms、页面 160ms、弹层进入 180ms、退出 120ms。
- 配置页与工作区仅在导航切换时淡入；编辑、自动保存和对话更新不会重播。快速切换会取消上一段动画。
- 页面过渡只改变透明度，不动画化布局尺寸；拖动、缩放和时间线定位保持直接响应。
- 弹层避免缩放文字；有关闭状态的 Radix 弹层分别应用进入与退出规则。
- 动画结束不保留 transform；系统启用减少动态效果时关闭装饰性过渡。
- 清理样式时优先删除确定被覆盖的同选择器声明，以及源代码中已无使用者的旧选择器，保留局部几何规则。

## 验证

构建、既有前端测试及格式检查；在桌面应用中逐页检查实际数据、滚动、编辑焦点、长标题、选中和弹窗。视觉验证不等同于重新验证模型生成或媒体导出结果。
