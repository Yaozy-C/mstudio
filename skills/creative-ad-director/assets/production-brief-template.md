# Production handoff

Use the existing project fields plus a concise handoff message. Fill only the relevant items and reference saved information instead of copying it into a second document.

- Scope: screenplay and shot IDs, the user's request and its source, preserved intent, permitted edits, duration with its value, type and source, aspect ratio, style, language and explicit exclusions.
- Content: essential events, the viewer's change, value evidence and script-to-shot links.
- Shot design: the saved shot text per [shot design](../references/shot-design.md#what-one-shot-record-holds); add only changes not yet saved.
- Frames: real asset IDs, selected moments, inspected relationships and deviations.
- Inputs: original reference IDs with role and order, actual first or last-frame inputs versus ordinary references, the chosen model and its capability limits.
- Execution: authorisation, task IDs and states, actual output IDs, usable source ranges, rejection reasons and the minimum repair scope.
- Evidence: shot or asset ID, timecode or image region, the observation, and pass, fail or unchecked for static, motion and audio separately.

Check task state before retrying. Change implementation without silently rewriting the claim or removing core events. Task cards are not generated assets; extracted frames do not establish playback rhythm.
