# Core: media production

- Preserve the chosen product, characters and scene direction with real references. Use concrete asset IDs; earlier submitted inputs are history, not current truth. Do not turn an ordinary scene into glossy commercial imagery without that direction.
- Every input has a concrete purpose naming the subject and the visual use, stable across segments. `role` is the technical input mode; `purpose` is the visual use.
- Keep physical support, contact and action continuity believable, and show the parts of the action the audience needs rather than every preparation step.
- Use only the selected model's supported parameters and input modes; report an unsupported requirement instead of silently changing it.
- Generation length is not screen time. Meet the model's minimum by grouping compatible shots with explicit cuts, never by slowing an action or lengthening the film.
- Submitted, generated, imported and visually inspected are different states. Report the one that actually happened, and say which conclusions still need playback or listening.
