# 受控生成与失败恢复

读本文件后按当前图像工具和图像技能操作。工具能力/参考数量未知时查可用接口，不编参数，不擅自切付费 API。图片必须由真实图像工具生成/编辑；代码可排版已生成素材，不能绘制占位商品图冒充结果。

编写或修改静帧 prompt 前读取 [单张图片提示词](../../creative-ad-director/references/image-prompt-writing.md)，按当前时刻的可见状态提炼脚本，不将镜头说明追加为模型正文。

## 生产前：减少未约束变量

仅为选中方案准备必要资产：原始商品事实参考、已选人物/场景、具体机位与关键状态。先解决参考冲突，不把全部历史图堆入提示词。

默认先做一张代表性样稿，兼顾本片关键关系和人物/场景视觉方向；已有适用、被接受的母图则复用，不每次重做样稿。人物重点看服装剪裁与配色、轮廓和姿态、手部与画面中的身体比例、商品是否被松垮衣料或大面积躯干抢走注意。欧美受众或不露脸都不能自动推出固定人物造型或某种美感标准；依据实际构图和用户反馈判断。

先检查样稿再展开范围内的少量分镜，不把仅技术合格的第一张默认记为用户审美认可。用户已否定人物或视觉方向时，停止沿用该母图及其后续生成，下一轮先交一张有明确造型变化的修正版；不要一边修该人物一边批量扩图。这是本次视觉纠偏的范围，不是要求每格审批。已有方向和整套授权时，内部检查后继续完成对应交付。

默认分镜用代表格表达故事，动作过程写在说明里；只有用户要求详细动作制作或一个缺失状态确实影响理解时，才补针对性关键格。不要为逐一证明每次接触而生成整套起中末帧。

明确用于规划的粗图、选中母图、制作用干净画面。粗图可简化背景，不可简化掉要验证的商品结构、接触或遮挡。生成总览只适合规划，不默认裁成最终独立画格。

## 同场景沿用母图，变化写成差异

同机位状态变化优先编辑已检查母图，锁背景、商品几何、身份和光线；只改变本格动作/状态。大机位变化使用原商品图及必要身份/环境参考重新生成。局部小改用当前合格图作编辑目标，避免顺带重做已确认内容。

每次编辑都重查整图，合格后才作为下一格母图；若局部修复引入更多漂移，回到最近合格版本。不连用未经检查的输出，不把累计错误当既定设定。

提示词保持一个主要状态，写清参考角色、固定项、允许改变和接触关系：

```text
用途/画幅：本次独立画格或试图。
参考：按实际输入顺序标注每张图的用途。
保留：商品结构、比例依据、背景、人物、道具等本镜固定项。
本格变化：相对已选母图改变的动作、位置和开合；起止状态中的哪一刻。
构图与物理关系：注意主体、路径、遮挡、手臂连接、抓握/支撑、落点。
项目明确要求无脸时：禁止任何人脸或局部五官，包括背景、反射和屏幕；写明本镜的人体裁切边界、允许动作及运镜范围，保证全程不露脸。
风格：符合本次方向的一套光线/材质/景深，不混叠互相冲突的风格。
针对性避免：上次已观察到的具体错误；不要泛滥负面词。
输出：独立干净画面；字幕/箭头后期加。
```

控制生成规模：调用前先列精简的最终画格清单；只为新增故事信息、必要状态或本轮范围内的修正发起生图。工具可能自动把每次输出展示给用户，不能假设重试是隐藏的后台过程；不要连续生成一串相似修图来代替一次明确的调整。最终呈现选用图和简短说明，过程记录留文件；不因要留记录继续增加图片。

保存实际提示词、参考顺序、工具、输入输出路径。可用参数照实记，没有公开的 seed/模型/控制能力不猜测，不承诺相同提示词可逐像素复现。

## 两种循环分开

**创意循环**解决期待、揭示、产品关联，见内容 skill 的 [导演设计](../../product-storyboard/references/director-hook.md)。**生成循环**解决商品结构、人体、构图、状态还原。因画面错误重画不自动推翻创意；因概念没看点而精修材质不算进展。

| 实际失败 | 对应处理 | 不该做 |
|---|---|---|
| 商品结构/颜色漂移 | 回原图，去冲突参考，针对部件编辑；重查依赖图 | 把错误图升级为商品标准 |
| 违反项目无脸要求，人脸或局部五官入画（含背景/反射/屏幕） | 裁切、改机位或重做，重查动作全程及依赖格 | 用模糊、口罩/墨镜或精修脸部放行 |
| 手腕/手臂断连、穿模 | 显示连接路径，简化单次接触，调整机位/遮挡；保留事件 | 堆“完美双手”反复抽图 |
| 前后物品无故复制/跳位 | 改状态差异与数量账，编辑发生错误的格 | 改文案掩盖图像矛盾 |
| 局部修复导致背景/身份漂移 | 回最近合格母图，缩小改动范围和参考集合 | 一直在受损输出上接力修 |
| 期待/兑现只能靠文字解释 | 回概念、信息线索或镜头调度 | 继续精修已失败的构图 |
| 动态速度/路径未知 | 输出运动计划；有条件再验证实际片段 | 多抽几张静帧冒充动态验证 |

同一个具体缺陷默认最多做两次有诊断依据的修正，每次记录假设、改动和观察；不是每图必须两次，也不是用户全部任务只有两次。首次已合格就继续。两次后同缺陷仍在，停止同方法抽样，改机位、接触方式或制作路线；改路线前确认原观看理由仍保留。

若可用路线仍无法表达核心事件，回内容 skill 判断替代方案；用户锁定该事件时保留该创意并报告未完成的制作部分，不暗换成普通演示。成本/尝试达到用户上限则交付已有合格部分与明确缺口；不要以持续重试隐藏无进展。

## 实际质感

商品还原、物理可信、跨格连续优先于风格修饰。风格选择依据当前目标，风格修饰不能掩盖结构错误。超现实事件只豁免创意明确指定的物理关系，其余人体、商品结构与比例仍须可信。

## 【重要｜感知真实感独立验收】

用户要求真实、自然、像实拍或降低 AI 感时，独立检查感知真实感；结构正确、无穿模、纹理丰富、高清或漂亮均不能代替此项。明确的插画/渲染风格按用户选择，不擅自改写为纪实。创意明确指定的超现实事件不要求真实发生，但未被指定改变的商品材质、人体、光线与受力关系仍须可信。

**扩展分镜前先过实拍感样稿关。**明确谁在什么环境、以什么机位记录什么动作。实际打开样稿，先看整体，再查关键区域：第一眼更像真实拍摄还是渲染/生成广告图？哪些可见细节支持判断？主因是布景、光线、材质、动作，还是组合过于整齐？不通过则先修样稿，不继续扩图；已有合格样稿可复用，不增加逐格用户审批。

- 软性商品随装载、支撑和提拉发生合理形变；不要只堆织物纹理，却让包体始终像硬壳。握持压力、提手张力、包体重量感须相互一致。
- 反光、阴影、粗糙度与实际光源及材质相符；不能把所有物体处理成相同的柔顺高光和精致表面。
- 场景与道具摆放服务正在发生的动作，不为展示而默认全部朝向镜头、对称排列或保持完美状态。棚拍可以真实，但不能未经选择就套用样板间、均匀柔光和正面居中的视觉配方。
- 不强制添加脏污、褶皱、杂乱或噪点。不完美须有使用或物理原因，不能形成另一套伪真实配方；不降低原本商品质量来制造生活感。

**参考分工：**商品原图约束身份与结构；真实拍摄参考约束环境、光线、机位和生活感。优先利用已有实拍资料，记录各自用途；无法取得拍摄参考时说明依据与未知，不虚构已做对照。生成母图仅用于连续性，不作为商品事实或实拍感的自证标准。

**失败处理：**定位主因后改变对应的布景、光线、构图或物理状态；不要仅追加“超写实、手机拍摄、电影感”、增强纹理或加噪点宣称修复。重新打开结果，记录具体可见变化与剩余问题。局部问题只改受影响区域；整体视觉基准失败则先重建样稿，再检查依赖图。沿用既有有依据修复次数与换路线条件。

审查单列感知真实感，与结构正确、故事成立分别判断。属于助手基于画面的感知判断，不声称证明摄影来源或所有观众感受；用户已明确指出 AI 感时不能以内部自评覆盖其反馈。


## 【重要｜真实商品部件不可遗漏】

生成前从当前型号的原始资料提取本镜应保留的部件：名称、所在区域、材质/形态、连接关系及来源定位。写入参考说明与固定项，不只写“保持商品一致”。未作为本片卖点的真实部件也必须保留，不能被模型省略、替换为底层材质或融入背景。

生成/编辑后对照原始资料逐项检查：本镜按机位与开合状态应可见的部件是否存在、位置是否正确、形态材质是否仍可辨。区分实际缺失、合理遮挡/画外与分辨率不足导致无法确认；不要求不可见部件强行入画，也不把“看不清”记成已保留。应可见却缺失或被替换属于阻断错误，即使整体像实拍也不能放行。

缺失时针对该部件修复，再核对整图及依赖帧。错误图不得作为后续商品参考；不要通过换机位隐藏遗漏来规避还原。商品事实来自原始资料，不以生成结果重新定义商品。具体商品部件留项目记录，不把某款结构变成所有商品默认。
