# Choose a controllable production route

Start from the shot's purpose and what must stay fixed. Routes combine; no vendor is the default. References constrain generation but do not lock pixels or geometry: verify preservation in the actual result.

| Control need | Route | Limit |
|---|---|---|
| Position, scale and composition | Layout sketch, annotated reference or static composite before generation | A layout is not a final product restoration |
| Clear start with limited change | Inspected production frame as `first-frame` | Motion can still alter parts |
| Existing action with visual changes | Source action clip as `video-reference` plus editing | Product regions can change too |
| Exact visible product details | Keep the original product layer and composite a separately generated environment or effect | A flat original does not solve new views, occlusion or soft-body motion |
| Exact timing, splits or graphics | Deterministic editing, masks and layer animation | Editing cannot hide missing required proof |

Reference the saved shot text per [shot design](../../creative-ad-director/references/shot-design.md#what-one-shot-record-holds); add the input roles, the chosen route, the reason, the risk and the fallback to the existing handoff rather than another camera table. Separate product fact, scene and camera baseline, composition, motion and actual control frames. Use the minimum relevant set and resolve conflicts before submission.

Test the hardest relationship within existing authorisation. An unclear static relationship needs a layout or design repair; a motion unknown needs an authorised useful test. Diagnose a concept, input, route or execution failure rather than appending adjectives. Under an all-generated requirement use the allowed reference-driven or segmented approaches; if essential output stays infeasible, report the gap without secretly changing the idea.

Rough cuts select material and pacing; a serious product error stays an error. Spend local repair and quality upgrades on retained shots. A vendor's consistency claim does not guarantee preservation. Compare the actual camera behaviour with the plan: cropping is not translation, and rotating the product is not an orbit.

## Preserve motion and editorial intent across routes

For motion-critical work, distinguish a text speed descriptor, a visual motion reference and an actual control input, and choose by available capability; a generic video reference does not guarantee timing or camera geometry. Confirm that the proxy motion and camera produce the intended visible result before comparing the generation against it; the model will not repair a slow or wrongly staged reference.

A generation group may contain several editorial shots only on a route that can express them. If that route fails, keep the selected events and cuts through separate supported generations and deterministic assembly. Keep the model's minimum length while selecting the shorter ranges you need; never turn requested montage cuts into continuous orbiting or slow action to match the API duration.
