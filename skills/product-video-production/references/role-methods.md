# Detailed production methods

Use for input, implementation or repair decisions requiring more detail. CORE.md is loaded automatically; these methods are read on demand.

Static composition, framePrompt, drawing and image repairs belong to the storyboard artist. Implement video and other requested media from saved shot designs and selected references within the current scope. Follow existing generation authorization without stage-by-stage approvals. Return a concrete missing action or camera relationship rather than rewriting the story. Read relevant model-specific methods and verify actual input capability, original product evidence, starting/ending state and reference roles. Own shot.prompt, not shot.framePrompt. Preserve key events and the film's creative intent; propose segmentation, staging or compositing when needed.

Create real tasks through request_generation using the selected model, and report actual states. Prompt-only edits use update_generation for a task or update_node for a shot draft, without generating. Do not claim unsupported capabilities or unproduced media. Repair only specified shots, parts and time ranges, retaining accepted results. Hand editing actual asset IDs, usable source intervals and relevant limitations.

Consult creative-ad-director/references/video-prompt-writing.md and selected-model methods as needed. Reduce director analysis to scene/subject relationships, key changes, effective camera/cuts and necessary sound rather than concatenating tables or stacking operations. Choose the minimum relevant references per generated segment; distinguish identity, scene, action state and actual first/last frames, recording input order. A multi-shot segment need not become one model call per shot. Inspect the final request including suffixes for repeated initial actions, contradictory shot counts, timing overload and reference contamination.

Identify the concrete relationship a trial must test. Prompt compliance is not output validity. Inspect from first appearance to destination: initial support, path, contact and ending state. A successful catch or insertion does not prove the starting position was correct. If a mid-action reference conflicts with the opening, use a compatible reference, tighter framing or the smallest useful action split within authorization; do not rely on additional negative words. Follow motion-and-editing.md to hand off shot IDs, actual assets, source ranges, observed events and keep/trim/discard/repair decisions. Without audiovisual access mark uninspected. Retain a usable later segment when possible but supply its missing causal opening.

Independently verify actual model modes, roles, parameters and final prompts. Handoffs and provisional storyboards are evidence, not substitutes for judgment. Return inconsistent camera, visible surfaces or duration to direction through coordination. A text request plus an ordinary reference is not equivalent to start/end-frame control. Implement user-locked aspect ratio, resolution and duration through supported parameters. Distinguish generated duration from edited shot duration; give editing the reason and interval for trimming. State concrete unsupported requirements and viable options rather than silently using defaults or pretending prompt text set an API parameter. Resolve routine choices yourself; escalate only changes to locked intent.

Preserve an accepted viewing experience while correcting execution. Actual reference geometry, opening and action state outweigh filenames; labeling an image 'not the first frame' does not remove conflicting state. Recheck all actual input roles when adding references. Return spatial conflicts with visible evidence; solve input and wording issues yourself. Do not weaken the concept or add fixed trial/approval stages.

When a generation card is referenced, its taskKey is the boundary. Inspect that task directly, then fetch only missing shot or asset fields. Save only update_generation unless the user also requested updating the shot draft. History and memory are context, not new assignments. Report the target, saved values and relevant unresolved gaps, without other-shot inventories or invitations. Unverified generation cannot prove a visual issue resolved.

Each new read should resolve a specific uncertainty affecting the current edit. Reuse complete unchanged context; refresh affected targets rather than the whole film when revision changes. Use actual IDs and returned pagination offsets. Once evidence supports the decision, save, verify and return; do not continue exploring for completeness or automatically act on out-of-scope dependencies.
