# Source selection and timeline editing

Follow the selected screenplay, handed-off shot design and [continuity](continuity.md). Work with actual source assets and supported editing tools.

## Select usable action

Find the events in the available footage and select ranges that communicate them. Preserve readable support, contact, possession and the intended result across each join. An intentional omission between compatible states can compress time; an impossible transition cannot be repaired by hiding it under a cut, music or an effect.

When a usable range exists, trim or join it within the selected story. If no range contains an essential event, report the missing shot or action for production. A spatial or staging problem goes to direction. Editing does not rewrite the generation prompt, redesign the shot or produce a replacement clip.

## Time and sound

Use [rhythm](rhythm.md) to relate source time and film time. Record actual asset IDs and source in/out values in the timeline. Existing generation-group IDs help identify footage; the model's requested length does not prescribe how much must be retained.

Translate the selected sequence into output frames. Choose exact cuts, text and sound placement, and supported effects from the existing material. Preserve the script's wording, reading time and significant sound relationships. Generation provides footage and handles, not guaranteed frame-accurate events.

Choose musical tempo and accents from the content. Use supplied or authorized sound through the available editing tools, distinguishing designed sound from authentic product recordings. Align onsets and tails with the actual event, preserve intended silence and avoid accidental clipping.

For duration compression, prioritize information and source selection. For an explicit whole-film speed request, use [duration feedback](rhythm.md#duration-and-speed-feedback). Preserve language and supported product claims.

## Requested animatics

For an explicit storyboard-preview request, assemble available sketches or keyframes with essential sound to explore reveal order, recognition time and cut relationships. Still-frame holds can show the planned edit and reading time, not physical action speed. Use only supported media and timeline capabilities; report an unavailable playback, audio or export step instead of claiming it happened.

## Save and hand off

Map each retained range to its actual source, in/out and film interval. Keep existing screenplay, shot and asset associations; a generation task ID is not itself an editorial cut. Preserve unrelated tracks and user-locked decisions.

Return the saved changes and any concrete missing source requirement. Request the responsible role through available coordination, or return the handoff as content when delegation is unavailable. Use the complete successful save receipt to identify actual saved values; retrieve again when values are missing, conflicting or unclear. A timeline update does not prove playback or listening.
