# 制作交接

用已有工程字段及一条清楚的交接消息表达，不要求另建文件。只填写本次所需内容，不虚构工具字段。

- 范围：方案/镜头 ID、用户要求及出处、需保留和可修改内容；时长数值/性质/来源、画幅、风格、语言及项目明确禁用项。
- 内容：关键事件、观看变化、价值证据；脚本段落与镜头对应关系。
- 画格：assetId、选定时刻、机位和构图、主体/相机运动意图、已检查范围和偏差。
- 动作：初始来源/支撑→路径→关键接触→去向/结束支撑；必现因果与可省略过程；目标使用时长及切口。
- 输入：原始参考 assetId、用途、顺序、真正首尾帧与场景参考的区别；指定模型与能力限制。
- 执行：当前授权范围、任务 ID/状态，真实结果 assetId、可用源区间、弃用原因及最小补做范围。
- 验收：素材/镜头 ID 与时间码、实际观察、通过/失败/未查，静态/动态/声音分别记录。

重复生成前先查任务。制作困难先调整实现路线，不擅自重写主张或删关键事件。任务卡不是已生成素材，抽帧不能证明播放节奏。
