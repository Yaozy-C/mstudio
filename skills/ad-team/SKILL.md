# Production coordination

Maintain the current goal, verified facts, user decisions and concrete dependencies. The application supplies the current specialist roster, tool permissions, delegation lifecycle and [core](CORE.md).

## Route the decision

| Work | Owner |
|---|---|
| Creative event and audiovisual script | Writer with [scriptwriting](../ad-script/SKILL.md) |
| Camera, blocking, action beats and continuity | Director with [shot design](../product-storyboard/SKILL.md) |
| Reusable white-background identity references | Asset specialist with [asset preparation](../asset-preparation/SKILL.md) |
| Scene frames, image prompts and local image repairs | Artist with [storyboard art](../storyboard-art/SKILL.md) |
| Video prompt, input roles and supported parameters | Producer with [production](../product-video-production/SKILL.md) |
| Footage selection, timeline, captions and sound | Editor |
| Color or a specific join | Colorist or transition designer |

A person appearing in a street scene is still a scene-frame task; the presence of a person does not turn it into white-background asset preparation. Commission shared references only for concrete consistency gaps across distinct shots, or an explicit asset request. Same-shot A/B continuity belongs to the artist.

## Handoff and dependency

Pass the current request, target IDs, permitted changes, supplied evidence, preserved intent and completion condition. Distinguish explicit user requirements from provisional designs and diagnoses. Leave professional camera, action and model choices to the responsible specialist.

Sequence work only for real dependencies. A dependent frame needs an inspected suitable anchor; a queued task or a returned child does not establish that evidence. Carry the exact unresolved relationship and ready condition into continuation. Reuse findings and actual IDs during recovery instead of redispatching the unchanged assignment.

Route story conflicts to the writer, spatial design conflicts to direction, image defects to the artist, input/motion failures to production and timeline issues to editing. Preserve an accepted viewing experience while allowing provisional implementation choices to change. After reasoned repairs stop improving the same defect, change approach or report the specific blocker.

Match handoff to the requested deliverable: saved script/design, frame assets, generated media with usable source ranges, or edited timeline. Report actual results and unchecked aspects. Review is useful when it answers a current question; it is not a compulsory workflow stage.
