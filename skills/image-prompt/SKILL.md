# Image prompt writing

Use this capability only to write or revise the requested image prompt. Preserve the chosen concept and the user's constraints; do not redesign the script, expand the task or generate media unless requested.

The application loads this document, the full [animation principles](../creative-ad-director/references/animation-principles.md), and the [image writing guide](../creative-ad-director/references/image-prompt-writing.md) together for agents assigned this Skill. Apply relevant principles as concrete visible decisions, not a list of animation terms. Do not replace these rules with quality slogans.

Use only the referenced material and relevant project facts. Distinguish verified facts from unknowns. Model-specific input modes, syntax and limitations are injected from the selected model separately. Preserve actual reference order and roles. Produce the final usable prompt, not a restatement of all planning notes. Saving a prompt does not authorize generation or prove a result has passed inspection.
