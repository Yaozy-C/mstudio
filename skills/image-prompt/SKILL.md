# Image prompt writing

Use this capability only to write or revise the requested image prompt. Preserve the chosen concept and the user's constraints; do not redesign the script, expand the task or generate media unless requested.

The application loads this document and the [image writing guide](../creative-ad-director/references/image-prompt-writing.md) for agents assigned this Skill. Use these supplied rules directly. Follow their links only for a relevant unresolved pose, motion, photographic appearance or performance question. Complete current model-specific guidance is supplied separately; query it only when missing or changed.

Use only the referenced material and relevant project facts. Distinguish verified facts from unknowns. Model-specific input modes, syntax and limitations are injected from the selected model separately. Preserve actual reference order and technical input modes. In generation tools, role selects the input mode (reference or edit); purpose describes what the image supplies, such as identity, geometry or composition. Produce the final usable prompt, not a restatement of all planning notes. Saving a prompt does not authorize generation or prove a result has passed inspection.
