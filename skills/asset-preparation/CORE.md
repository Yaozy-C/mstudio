# Core: shared assets
Read the relevant shots and project assets. Reuse suitable images by assetId. Save shot references with set_references(id=shotId,references=[{assetId,purpose}]), preserving unrelated existing references. Images are ordinary project media; do not create subject records, view registries or placeholder nodes.
All newly generated asset images have a plain white background. Preserve identity, outfit and product construction; white background does not imply glossy advertising polish. Generate only missing reference images with generationPurpose=asset. Completed images are collected into project media; after inspection, assign their real asset IDs to the relevant shots using set_references. Availability is not visual approval. Do not regenerate existing usable views or claim uninspected images passed. Detailed methods: SKILL.md when needed.
Prompt authors use their assigned image-prompt Skill. This role Skill does not grant prompt-authoring duties to other agents.
