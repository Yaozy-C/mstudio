# 创意与声画脚本

先依据当前目标、原始商品材料和已选决定写作。新创作不自动继承旧剧情；缺失事实不写成性能承诺。需要比较方向时参考 [概念设计](../creative-ad-director/references/concepts.md)，不为明确的局部修改重开创意。

## 写入工程

plan 的 text 写创意，plan.story 写故事概述；plan.script 按事件推进组织段落，沿用对应 ID。每段使用现有字段：
- title：事件名称，不重复界面编号。
- action：观众实际看见的事件与变化，用可拍摄的描述；可保留决定表达的视角或揭晓方式。
- onScreenText：画面上准确出现的文字；无则空字符串。与台词分开。
- dialogue：实际说出的台词或旁白；无则空字符串。
- sound：影响理解或节奏的音效、音乐、停顿及其动作落点。
- duration：暂估秒数，兼顾动作完成、台词和画面文字辨认；用户锁定或上限另按明确要求处理。

不要把相机距离、帧率、生成参数、重复禁用清单写入脚本正文。特殊摄影设计只有决定创意能否成立时才在 action 简述，详细调度留给分镜导演。明确决定创意的观看效果与必现事件，让导演能调整实现而不丢掉意图；不要把自己暂拟的完整操作、机位数字或时长写成用户锁定。内部检查每段的新信息与价值兑现，不逐段粘贴分析清单。画面文字表达的利益须有对应事件支持。

例如开盖揭晓：action 可写“从包内看，上盖掀起，光照亮内衬与有序摆放的物品”，onScreenText 单独写短句，sound 写开盖动作对应的声音。不是必须完整表现拉链全程；若完整过程是用户要求或利益证据，则保留并重新估时。示例不是固定广告套路。

## 交接

交方案 ID、关键事件、必须保留项、可省略准备过程和时长性质。脚本段落不是镜头；暂估时间不限制后续导演合理分配。只写脚本则保存后结束；完整制作请求沿用既有授权，由统筹安排后续。局部修改保留无关内容、媒体和段落关联。不要自动迁移旧段落中含义不明的字幕或旁白。
