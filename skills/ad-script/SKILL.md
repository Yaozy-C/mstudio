# Concepts and audiovisual scripts

Write from the current goal, original product evidence and selected decisions. A new commission does not inherit the previous story. Missing evidence cannot become a performance claim. Use [concept development](../creative-ad-director/references/concepts.md) when comparing directions; a clear local edit does not reopen ideation.

## Save the script

Write event-driven sections directly to screenplay.script on a screenplay node. There is no separate promotional-plan document or global synopsis/sound field. Reuse section IDs and actual fields:

- title: event name, without duplicating interface numbering.
- action: visible events and changes; include a viewpoint or reveal only when it determines the idea.
- onScreenText: exact onscreen copy, or an empty string; separate from speech.
- dialogue: actual dialogue or narration, or an empty string.
- sound: meaningful effects, music, pauses and their event relationship.
- duration: provisional seconds allowing action, speech and reading; distinguish user locks and maxima.

Do not fill script prose with camera distances, frame rates, generation parameters or repeated exclusion lists. The director owns detailed blocking. Distinguish the essential viewing effect/event from provisional staging, full operating sequences and timing. Check information and value internally rather than pasting a checklist into every section. Claims in copy need corresponding supported events.

An inside-container reveal can show opening, incoming light and organized contents without requiring every outside fastening operation. Preserve a complete process if it is explicitly requested or essential proof; then revise staging/time. This is an example, not a default story.

## Handoff

Return screenplay ID, essential events, preserved intent, omittable preparation and duration type. Script sections are not shots; estimates permit the director's justified reallocation. A script-only task ends after saving. A full-production request continues through the coordinator under existing authorization. Local edits preserve unrelated sections, associations and media. Do not guess whether ambiguous old text is dialogue or an onscreen caption.
